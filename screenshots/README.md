# Captures d'écran

Place ici tes captures d'écran une fois l'application lancée, par exemple :

- `home_light.png` — Écran de liste, thème clair
- `home_dark.png` — Écran de liste, thème sombre
- `detail.png` — Écran de détail d'une recette
- `form.png` — Formulaire d'ajout avec validation
- `tablet.png` — Vue en grille sur tablette / écran large

Pour capturer une image :
- **Émulateur/simulateur** : bouton de capture de l'IDE (Android Studio / VS Code) ou raccourci du système.
- **Chrome (flutter run -d chrome)** : capture d'écran classique du navigateur.

Pense ensuite à référencer ces images dans le `README.md` principal, par exemple :

```markdown
![Écran d'accueil](screenshots/home_light.png)
```
